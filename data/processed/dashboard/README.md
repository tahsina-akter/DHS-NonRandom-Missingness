# Dashboard Data

This folder contains the processed data used by the optional interactive Shiny dashboard.

The dashboard data are generated by:

`Stata/11_dashboard.do`

## Contents

This folder contains two CSV files:

- `overview.csv` — contains overall height measurement usability summaries by country and survey period, including the percentage of usable and unusable height measurements and the corresponding sample size.

- `subgroup.csv` — contains height measurement usability summaries for selected subgroups, including household wealth, maternal education, residence, and child sex, by country and survey period.

These files are used by:

`R/12_Dashboard.R`

to populate the interactive dashboard.

## Workflow

Run:

`Stata/11_dashboard.do`

to generate the dashboard data files.

Then run:

`R/12_Dashboard.R`

to launch the interactive Shiny dashboard.

The dashboard is an optional component of the project and is not required to reproduce the main statistical analyses.
