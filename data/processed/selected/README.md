# Selected and Pooled Data

This folder is used to store the pooled and selected DHS dataset generated from the raw Children's Recode (KR) files. The generated dataset is not included in the repository.

The dataset is generated by:

`Stata/01_Variables_selection_and_pooled_data.do`

The script:

- selects the variables required for the study from each DHS survey round;
- harmonizes the selected variables across countries and survey years; and
- pools the individual survey datasets into a single analytical dataset.

The main dataset created at this stage is:

`dhs_combined.dta`

This dataset contains the eleven DHS survey rounds from Bangladesh, India, Nepal, and Pakistan used in the study.
