# Multiple Imputation Data

This folder contains the datasets and R object generated during the multiple imputation analysis.

The imputation is performed using:

`R/07_multiple_imputation.R`

Multiple imputation is carried out using **Predictive Mean Matching (PMM)** with **20 imputed datasets**. HAZ (`haz`) and child age in months (`child_age_months`) are imputed, while the survey design variables are retained for the subsequent survey-weighted analysis.

## Contents

The imputation workflow generates:

- `dhs_imputation.dta` — the original imputation dataset (m = 0) containing the variables used in the imputation procedure.
- `dhs_imp_1.dta` through `dhs_imp_20.dta` — the 20 completed imputed datasets.
- `imp_pmm.rds` — the saved `mice` imputation object.

The complete set of imputed datasets may be relatively large. If the files are not included in a particular repository distribution, they can be regenerated by running `R/07_multiple_imputation.R`.

## Next Step

After completing the multiple imputation in R, run:

`Stata/08_multiple_imputation_analysis.do`

This script uses the imputed datasets to perform the survey-weighted HAZ regression and compare the multiple-imputation results with the complete-case analysis.
